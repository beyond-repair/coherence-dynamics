# Limitations

## Current Scope

- Research foundation only. No universal theory of everything.
- No fitting of astronomical data as the starting point.
- Ware Constant is historical context only.

## Methodological

- Graph spectral results are mathematical laboratories, not automatic physical predictions.
- Effective-action calculations are controlled only within stated approximations and regulators.
- Passing software tests establishes that an implementation satisfies the tested condition; it does not, by itself, validate the physical theory.

## Provenance

Prior repositories contain results under specific assumptions. Unsupported claims are not imported. See `research_log/provenance.md`.

## What Is Not Claimed

- Derivation of a new force or modified gravity.
- Selection of a universal numerical constant.
- Cross-scale unification without evidence at each scale.
